# 🚀 Intranet Post Creator - Team Installation Guide

## 📥 Quick Installation (5 minutes)

### Step 1: Download & Extract
1. **Download** the `intranet-extension.zip` file 
2. **Extract** it to your Desktop (or any folder you prefer)
3. **Remember the folder location** - you'll need it in Step 3

### Step 2: Enable Developer Mode
1. **Open Chrome** and go to `chrome://extensions/`
2. **Toggle "Developer Mode"** in the top-right corner (it should turn blue)

### Step 3: Install Extension
1. **Click "Load unpacked"** button
2. **Select the extracted folder** (the one with `manifest.json`)
3. **Click "Select Folder"**
4. **Pin the extension** by clicking the puzzle piece icon → pin the extension

### Step 4: Configure Your API Token (Required)
1. **Click the extension icon** in your Chrome toolbar
2. **Click "⚙️ Settings"**
3. **Get your personal API token**:
   - Go to [your intranet profile](https://intranet.example.com/profile)
   - Scroll to "API Token" section
   - Click "Generate New API Token"
   - Copy the generated token
4. **Paste your token** in the extension settings
5. **Click "Verify & Save Token"**

## ✅ You're Done!

The extension icon should now appear in your Chrome toolbar. Click it to create posts!

## 🤔 Need Help?

### Common Issues:

**Extension won't load:**
- Make sure you extracted the ZIP file completely
- The folder should contain `manifest.json` 
- Enable Developer Mode first

**Can't create posts:**
- Make sure you've set up your personal API token
- Check that the token verification was successful
- Try regenerating your API token if it's not working

**Need your API token again?**
- Go to https://intranet.example.com/profile
- Generate a new one if needed

### Still Having Issues?
Contact your intranet admin or ask in the team chat!

## 🎯 How to Use

### Quick Post from Any Page:
1. **Click the extension icon** while browsing any webpage
2. **Title and content will be pre-filled** with page info
3. **Edit as needed** and click "Create Post"
4. **Your post appears** on the intranet as you!

### Quick Templates:
- **🚨 Alert** - For urgent issues
- **📢 Update** - General announcements  
- **🚀 Deployment** - Release notifications
- **📊 Report** - Analytics and metrics

### Smart Context Detection:
The extension automatically detects when you're on:
- **Monitoring dashboards** (New Relic, Datadog, etc.)
- **CI/CD platforms** (Jenkins, GitHub Actions, etc.)
- And suggests appropriate post templates
