# Icons for Intranet Post Creator Chrome Extension

This directory should contain the following icon files for the Chrome extension:

## Required Icons

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store and installation)

## Icon Design Guidelines

The icons should represent the extension's purpose: creating posts for an intranet forum. Consider using:

- A document or post icon
- A rocket or launch symbol (🚀)
- Your brand colors (purple/blue gradient)
- Clean, simple design that works at small sizes

## Creating Icons

You can create these icons using:
- Design tools like Figma, Sketch, or Adobe Illustrator
- Online icon generators
- AI image generation tools

## Temporary Solution

Until you create custom icons, you can:
1. Use any 16x16, 48x48, and 128x128 PNG images
2. Rename them to match the required filenames
3. Replace them later with your custom designs

## File Format

- **Format**: PNG (recommended) or JPG
- **Background**: Transparent or solid color
- **Style**: Flat design works best for Chrome extensions
